Fashion Design Chatbot

Modify clothing designs through natural language

An AI-powered web application that lets users redesign clothing items through plain English commands. Upload a clothing image, then instruct the system to change the neckline style, adjust sleeve type, swap colors, or alter the length — and the AI applies those changes directly to the image. Combines NLP-based intent understanding with deep learning image generation for a seamless design experience.

  • Full undo/redo history to navigate through design iterations
  • Flask web app with real-time chat interface and split-screen image preview
